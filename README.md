# NEXUS Support Page

Simple static GitHub Pages support site for the NEXUS Garmin watch face.

## Before publishing

Replace:

- `YOUR_EMAIL@example.com`
- Garmin Store link
- Optional Telegram/community link if you want to add one

## How to publish on GitHub Pages

1. Create a new GitHub repository, for example: `nexus-support`.
2. Upload `index.html` and `styles.css`.
3. Open repository settings.
4. Go to **Pages**.
5. Select **Deploy from a branch**.
6. Select `main` branch and `/root`.
7. Save.
8. Your page will be available at:

`https://YOUR_GITHUB_USERNAME.github.io/nexus-support/`
